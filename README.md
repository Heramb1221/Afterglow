# About The Project

Afterglow is a cinematic frontend experience designed to explore modern frontend engineering principles through immersive interaction systems and animation-driven UI architecture.

The project combines:

- Responsive layout systems
- Premium typography
- Glassmorphism-inspired UI
- Dark/light theming
- GSAP-based motion orchestration
- Cinematic scrolling behavior

Rather than functioning as a traditional CRUD application, Afterglow focuses on creating a visually immersive digital experience while maintaining scalable frontend structure and clean styling practices.

---

## Engineering Goals

This project was built to experiment with:

- Animation timing systems
- Smooth interaction flows
- Motion orchestration
- UI layering
- Responsive rendering behavior
- Visual storytelling
- Frontend architecture without framework abstraction

# Performance Considerations

## Optimizations Implemented

- Lightweight dependency usage
- GPU-friendly animations
- CSS variable reuse
- Minimal JavaScript footprint
- Static asset architecture

---

## Potential Bottlenecks

| Issue | Impact |
|---|---|
| Heavy animation stacking | Reduced performance on low-end devices |
| Excessive blur/filter rendering | GPU-intensive rendering cost |
| Large texture overlays | Increased paint/composite workload |


---

# Tradeoffs & Limitations

## Current Limitations

- No backend integration
- No persistence layer
- No CMS/admin controls
- Limited accessibility optimization
- Heavy visual focus over functional complexity

---

# Known Issues

- Some animations may feel intensive on low-end devices
- Blur effects may render inconsistently across browsers
- Mobile animation timing may require additional tuning

---

# Challenges Faced
